# 主页刷新、悬停明暗与图标

2026-10-14。交付 `/Users/lyx/Applications/RhineMusicNative.app`。

## 诊断与修复

1. 主页播放的缓慢环境动画原本进入 20 fps 档位，悬停／切歌才回到 60 fps。新增测试在旧逻辑下得到 20 与 60 不相等的失败。现在主页统一请求 60 fps；暂停且完全静止依然停止 Metal 刷新。详情低速环境动画仍保留原来的低帧率档位。
2. 负载自适应级别升高后，旧逻辑在 moving 时关闭 AO，静止时重新开启。同一场景因此突然变浅／变深。回归测试在三个自适应级别复现失败。音乐模式现在保持 AO 状态一致，避免悬停收尾时换用另一套光照。
3. 固定指针测试覆盖 160 个场景点、每点连续 36 帧，没有发现抬升后反复切换悬停目标。未将“拾取抖动”列为已证实原因。
4. 透射背面已有单独捕获通道，主通道只绘制正面，减少重复工作。曾尝试按相机深度排序实例，但复测没有证明帧耗时改善，已撤回排序。保留全分辨率与 4× MSAA。

首次基线 GPU 主页平均 18.40 ms／p95 26.30 ms；稍后旧版复测恢复到 4.92 ms／p95 6.20 ms，说明存在明显外部负载波动。实验版为 5.10 ms／p95 6.89 ms，不能据此宣称数倍性能提升。本次确定性的改善是主页刷新档位与阴影状态连续性。

## 外观与反馈

- 顶部导航／播放控件上移 20 个设计坐标点，品牌标头保持。
- 图标由现有矢量标志重新绘制：深蓝单层底板、大尺寸冷白标志、淡扫描弧和琥珀色定位方块。生成完整 16–1024 像素 ICNS 尺寸。
- 按钮文字保持固定；悬停时角标描出、细线与端点扫过。点击位置的小圆弧和角标向中心收拢，沿用视频的扫描／定位语言。弱动态模式保留低运动反馈。
- 动效参考 [Apple Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/) 与 [Hover interactions](https://developer.apple.com/videos/play/wwdc2025/303/) 中的连续反馈、文字锚定原则；具体图形来自项目原片。
