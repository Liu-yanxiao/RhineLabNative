# 原生音乐播放器试听验证

日期：2026-10-13。产物：`build/RhineMusic.app`。参考 V0.3.0 的玻璃 CD 架、详情歌单及独立播放状态；默认进入音乐界面，原档案入口仍可用 `--archive`。

交付试听副本：`/Users/lyx/Applications/RhineMusicPreview.app`。该副本用不携带扩展属性的复制方式生成，已通过 `codesign --verify --deep --strict`。桌面目录的文件提供器会自动写回 FinderInfo，导致工程目录副本的严格签名检查失败，因此交付使用 Applications 中的已验证副本。若旧窗口已打开，退出后再启动新副本才能使用最终修复。

## 已实现

- 古风 DJ、开车小曲、热血、流行及个人收藏歌单；玻璃盒抽取、旋转和频道/歌单浏览。
- 网易云元数据搜索；频道缓存超过 7 天时在打开频道时更新，也可手动更新。搜索点 ＋ 加入自建歌单，心形按钮收藏。
- AVPlayer 在线播放，随机队列、连续下一首、上一首、暂停继续、快进、音量与停止。浏览状态与播放队列独立。
- 星海 / HYW 优先音源选择；地址解析或有效性检查失败后尝试备用音源。加载中暂停/停止或换曲会取消旧请求，迟到结果不能重新启动播放。
- 歌单持久化到 Application Support；临时音频地址不存进歌单。没有执行第三方音源脚本，只通过显式 JSON 接口适配。

## 实际验证

生产包命令 `build/RhineMusic.app/Contents/MacOS/RhineLab --music-check` 对星海和 HYW 分别进行静音 AVPlayer 检查：

1. 搜“古风DJ”，从前三个结果选样本。
2. 真实播放器进入 playing，时间推进超过 1 秒。
3. 暂停后时间停止推进，继续后重新推进。
4. 拖动到 12 秒，确认播放器时间到达目标。
5. 下一首切到第二个样本并重新推进进度。

最终两个音源均输出 PASS，未使用备用音源替代所测音源；检查不向扬声器出声，不写入用户偏好。它证明短时间原生播放控制链路通过，不代表整首持续播放、所有歌曲、其他平台或全部音质通过。

`swift test`：4 项通过，0 失败。覆盖加载中暂停的迟到回调、快速下一首后停止、歌单/收藏保存与去重、有效缓存避免重复更新。

实际窗口检查确认首页与详情的歌单、曲目、播放条和操作按钮存在。SwiftUI ImageRenderer 对原生 Slider/Menu/ScrollView 的离屏合成有占位/缺失，因此离屏截图不能代表这些控件的实际窗口效果。

## 本轮发现并修复的播放问题

音源有时返回 HTTP CDN 地址，命令行 AVPlayer 可以播放，但打包应用受 ATS 约束，错误 -1022。对同一地址的最小打包探针，HTTP 失败、HTTPS 成功。播放器改用 HTTPS，没有添加全局 ATS 放宽设置。

星海还曾返回已过期的签名地址，音频端返回 403。解析请求增加缓存刷新参数与 no-cache，并在安装 AVPlayerItem 前以 HEAD 检查可用性；过期地址触发备用源。最终生产包原始回归命令对两个音源均通过。临时调试输出已移除，最小探针移至 /tmp 的调试目录。

## 当前范围

试听请求 128k，不承诺无损或精确码率；没有加入歌词、EQ、远程控制、在线账号歌单同步或跨平台音源匹配。内容授权及服务条件的研究边界见 [音源研究](audio-source-research.md)。本地缓存保存歌曲元数据和用户选择，不下载整曲。
