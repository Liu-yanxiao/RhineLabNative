## 实现

- 正常音乐模式启动完整 BootMotion，约 20 秒；恢复 BootView 的权限、标志、圆环、欢迎和淡出。音乐模式此前直接 finishBoot、3.2 秒截断与不展示 BootView 三处绕过均已处理。
- 同一完整流程支持浅色及深蓝／冷白的深色配色；启动时可切换主题、按 Enter／Esc 或点击 ENTER SYSTEM 跳过。设置提供“重播终端启动”。弱动态模式减弱扫描与标志运动。
- 播放详情回到场景内的细线标注和渐隐阅读区。当前歌曲成为主要标题；更多来源、顺序、歌单信息进入信息标签，不再以六格字段占据主体。
- 音乐库、搜索、收藏和设置共用终端页结构：左侧章节标题与编号、右侧内容、同一品牌与返回位置，背景保留主场景的微弱透光。原有曲库和播放数据不重置。
- 点击位置出现短暂方形定位标记；按钮有按压、细线展开和悬停响应。标签指示线跟随选择，播放／收藏符号随状态变化，搜索时显示圆环扫描。进入页面有短暂分层展开；减弱动效设置与系统减少动态效果会抑制相关运动。

交互动效参考 [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 与 [Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)，具体图形沿用视频的细线和方形标记。
