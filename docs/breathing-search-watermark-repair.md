# 呼吸动画、搜索和背景层修复（2026-10-14）

## 根因与验证

实际系统单调时钟约 1,336,156 秒。先把绝对时间转成 Float 会产生 0.125 秒的量化间隔，60 Hz 动画连续多帧使用同一相位，再突然跳动。现在先在 Double 下取周期，再转换为 Float；同时修正主界面与播放页的周期动画。

回归测试在模拟长时间运行的时钟上驱动真实 ArchiveEngine。修复前 119 个帧间隔只有 79 次位置变化，最大跳变 0.01068；修复后 119 次均连续变化，最大跳变低于 0.004。此结果证明时间量化问题修复，不等同于所有设备上的 GPU 帧率保证。

## 界面

- 底部歌曲刻度最多显示 15 个，围绕当前歌曲移动，固定宽度，不再挤占歌单切换区。
- 歌曲更多菜单隐藏系统重复的下拉指示，仅显示省略号。
- 降低浅色子页面遮罩和叠加渐变的不透明度。
- 莱茵标志使用一次生成的纹理，在背景合成中绘制；主页面、音乐库、收藏居中，搜索和设置靠右，播放页位于右侧。主场景通过深度/覆盖率遮罩保护前景唱片。页面文字和按钮始终在其上层。

## 搜索

合并同关键词的并发请求；成功结果缓存 5 分钟，最多 20 个查询；保留页面搜索状态，优先显示本地匹配。失败不缓存，可重试。

真实首次请求分别测得 2.889 秒、6.354 秒，重复查询约 0.0001 秒。首次延迟仍受上游影响。另测匿名元数据接口，返回格式及可用性不一致，未将其加入正式搜索路径。
