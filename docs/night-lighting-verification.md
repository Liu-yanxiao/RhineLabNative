# 切列手势与深夜局部亮光

2026-10-14，延续歌单列与同歌单换歌的结构。

## 改动

- 音乐库横向触控板切列阈值从 40 点改为 110 点；一次有开始／结束阶段的手势最多提交一次，横向惯性忽略。首次有效移动确定主轴，避免上下浏览时横向漂移误切列。垂直歌曲循环保留连续滚动。无阶段的横向鼠标滚轮有 350 ms 间隔；键盘和按钮保持原响应。
- 参照 V0.3.0 的 `src/music-lighting.ts`，增加从画面左下方进入的冷色局部侧光、脊边散射与顶部细亮边。灯光锚点使用当前实际选中封面的位置／姿态，直接跟随既有弹簧动画，因此切列、换歌、打开和返回连续移动，行坐标重定位不会留下旧灯光。
- 音乐深夜环境改为低强度冷色底光；选中列及邻列由局部光提亮，外围保持深蓝。散射只作用于玻璃壳，封面印刷仍独立。沿用现有 Metal 光照通道，未增加灯光阴影通道、全屏辉光缓冲或图片缓存。原档案模式及暖昼亮光逻辑保留。
